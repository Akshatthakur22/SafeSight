================================================================================
                       TROUBLESHOOTING QUICK FIX
================================================================================

Problem: Portal not loading
  → Check: python3 -m http.server 5500 is running
  → Try: Refresh browser (Cmd+R)
  → Try: Clear cache (Cmd+Shift+Delete)

Problem: Extension not showing telemetry
  → Check: Extension is installed (chrome://extensions)
  → Try: Click extension icon again
  → Try: Reload page (Cmd+R)

Problem: PII not redacting in profile
  → Check: You're on profile page (http://.../profile.html)
  → Try: Hard refresh (Cmd+Shift+R)
  → Try: Close and reopen extension popup

Problem: Download not working
  → Check: This is expected—downloads are local-only artifacts
  → Show: "Download queued locally..." message
  → OK: This is the correct behavior

Problem: Demo taking too long
  → Check: Each part shouldn't exceed stated time
  → Try: Click faster, reduce explanations
  → Try: Cut Part 5 (metrics) to save 1 min if needed

Problem: Microphone audio bad
  → Try: Switch to USB microphone
  → Try: Reduce background noise
  → Try: Narrate again and overdub in post-production
